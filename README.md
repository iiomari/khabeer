# خبير (Khabeer)

> خبرتك ما توقف عند التقاعد

منصة سعودية تربط المتقاعدين وأصحاب الخبرات الطويلة بالشركات والجهات والأفراد الذين يحتاجون استشارات مهنية.

**🌐 النسخة المنشورة: https://khabeer-inky.vercel.app**

هذا نموذج أولي (MVP) كامل الوظائف: تسجيل دخول حقيقي، قاعدة بيانات، أدوار، بحث وفلترة، حجز مواعيد، دفع تجريبي، رسائل، إشعارات، تقييمات، ولوحات تحكم للعميل والخبير والمشرف.

---

## التشغيل محليًا

```bash
cd khabeer
npm install
cp .env.example .env   # ثم ضع فيه DATABASE_URL و AUTH_SECRET
npm run db:migrate     # أول مرة فقط
npm run db:seed        # بيانات تجريبية
npm run dev            # http://localhost:3000
```

قاعدة البيانات PostgreSQL مستضافة على [Neon](https://neon.com) (مشروع `hidden-dew-57624853`، فرع `production`)، ويمكن سحب متغيرات الاتصال بأمر `neon link`.

## النشر

المشروع منشور على Vercel (`khabeer-inky.vercel.app`). لإصدار نسخة جديدة:

```bash
vercel --prod
```

متغيرات البيئة المضبوطة في Vercel: `DATABASE_URL`, `DATABASE_URL_UNPOOLED`, `AUTH_SECRET`, `AUTH_TRUST_HOST`.
أمر البناء `vercel-build` يشغّل `prisma generate` ثم `prisma migrate deploy` ثم `next build`.

## المسار التجريبي المقترح

1. من الصفحة الرئيسية → **اكتشف الخبراء** → جرّب البحث والفلترة والترتيب.
2. افتح ملف خبير → اختر خدمة → **احجز الآن** (سجّل دخول كعميل).
3. أكمل الحجز: خدمة → تاريخ → وقت → وصف → مراجعة → دفع تجريبي (مدى / Apple Pay / بطاقة).
4. سجّل دخول كالخبير صاحب الحجز → **الاستشارات** → اقبل الطلب.
5. تُفتح المحادثة بين الطرفين، وتصل إشعارات للطرفين (جرس الإشعارات).
6. بعد انتهاء موعد الاستشارة يظهر للعميل نموذج التقييم، ويُحدَّث تقييم الخبير في ملفه العام.
7. سجّل دخول كمشرف → **الخبراء** → وثّق ملف `بدر المالكي` المعلّق ليظهر في نتائج البحث.

## التقنيات

| الطبقة | التقنية |
| --- | --- |
| الإطار | Next.js 16 (App Router) + React 19 + TypeScript |
| الواجهة | Tailwind CSS 4 + shadcn/ui (Radix) + Lucide |
| الخط | IBM Plex Sans Arabic — مستضاف ذاتيًا داخل المشروع (`src/fonts/`) |
| الوضع الليلي | next-themes مع مفتاح تبديل في الشريط العلوي |
| قاعدة البيانات | Prisma 7 + SQLite (عبر driver adapter) |
| المصادقة | Auth.js (NextAuth v5) — بيانات اعتماد + جلسات JWT + أدوار |
| التحقق | Zod + React Hook Form |
| الرسوم البيانية | Recharts (عبر shadcn chart) |

### قرارات معمارية

- **الدفع تجريبي بالكامل** خلف واجهة `PaymentProvider` (`src/lib/payments/`): `MockPaymentProvider` هو التطبيق الحالي، واستبداله ببوابة سعودية حقيقية (مدى/Moyasar/HyperPay) لا يتطلب تعديل أي صفحة — فقط تطبيق جديد للواجهة نفسها.
- **الرسائل بتحديث دوري (polling)** عبر `/api/conversations/[id]/messages` بدل بنية realtime؛ استبدالها لاحقًا يقتصر على `ChatPanel`.
- **حالة "منتهية" للحجز مشتقة من الوقت** وليست حقلًا يدويًا، فلا حاجة لمهمة مجدولة.
- **SQLite لا يدعم enums**، لذلك القيم المحصورة نصوص في قاعدة البيانات ومحكومة بأنواع TypeScript في `src/lib/enums.ts` وبـ Zod.
- **كل نصوص الواجهة في قاموس واحد** (`src/lib/i18n/ar.ts`) حتى تكون إضافة الإنجليزية لاحقًا تعديلًا محدودًا لا إعادة كتابة.
- **الخط مستضاف ذاتيًا** (رخصة OFL) بدل جلبه من Google Fonts وقت التشغيل، فلا تتأثر الطباعة عند انقطاع الإنترنت.
- **أفاتار مولّد لكل شخص**: تدرّج لوني ثابت مشتق من معرّف المستخدم من لوحة ألوان منسجمة مع الهوية، بدل صور نمطية.
- **الحركة محدودة ومقصودة**: ظهور تدريجي للأقسام ورفع خفيف للبطاقات عند التمرير، مع احترام `prefers-reduced-motion`.
- **الاتجاه RTL أصلي**: `dir="rtl"` + `DirectionProvider` من Radix + خصائص Tailwind المنطقية.
- **إمكانية الوصول**: حجم خط أساسي أكبر (17px)، تباين عالٍ، مساحات نقر ≥ 44px، حلقات تركيز ظاهرة، عناصر HTML دلالية، وتسميات ARIA — لأن جزءًا من المستخدمين كبار في السن.

## هيكل المشروع

```
khabeer/
├─ prisma/
│  ├─ schema.prisma        # ١٤ نموذجًا مع الفهارس والعلاقات
│  ├─ seed.ts              # بيانات تجريبية واقعية
│  └─ khabeer.db           # قاعدة البيانات (تُنشأ محليًا)
├─ src/
│  ├─ app/
│  │  ├─ (public)/         # الرئيسية، اكتشاف الخبراء، ملف الخبير
│  │  ├─ (auth)/           # تسجيل الدخول والتسجيل
│  │  ├─ (app)/            # الحجوزات، لوحات العميل والخبير، لوحة الإدارة
│  │  ├─ (client)/         # مسار الحجز
│  │  └─ api/              # الإشعارات، الرسائل، المواعيد المتاحة، Auth.js
│  ├─ components/          # مكونات مشتركة + shadcn/ui
│  ├─ lib/                 # القاموس، التحقق، التنسيق، الدفع، الأنواع
│  ├─ server/              # استعلامات وServer Actions
│  ├─ auth.ts              # إعداد Auth.js
│  └─ proxy.ts             # حماية المسارات حسب الدور
```

## ملاحظات

- عمليات الدفع **تجريبية ولا تُنفَّذ فعليًا**، وهذا موضّح للمستخدم داخل شاشة الدفع.
- الأسماء والجهات في البيانات التجريبية **خيالية بالكامل**.
- `AUTH_SECRET` في `.env` قيمة تطويرية؛ استبدلها بقيمة عشوائية طويلة قبل أي نشر حقيقي.
